# Steam Desktop Authenticator macOS v1.0.0

This is the first macOS release of the Steam Desktop Authenticator port. It is **not** upstream Windows SDA version 1.0.15.

```text
Release status: READY FOR UNSIGNED PUBLIC RELEASE
Code signing: Not provided
Apple notarization: Not provided
Gatekeeper manual approval may be required on first launch
```

This build is unsigned and not notarized by Apple. macOS cannot verify the developer identity. Only continue if you downloaded the app from the official repository and trust this project:

https://github.com/Nardo021/SteamDesktopAuthenticator-macOS

## Downloads

| Mac | File |
| --- | --- |
| Apple Silicon (M1 / M2 / M3 / M4 and later) | `Steam-Desktop-Authenticator-macOS-1.0.0-arm64.dmg` |
| Intel | `Steam-Desktop-Authenticator-macOS-1.0.0-x64.dmg` |

Apple Silicon users should use the **arm64** build. The `x64` build is for Intel Macs.

Also attach `SHA256SUMS.txt` from the same release and compare it to the DMG you downloaded.

## What's Included

Ported from the original Windows SDA workflow:

- Steam Guard code generation
- Multiple accounts
- Original `.maFile` / `manifest.json` compatibility
- Legacy SDA encryption compatibility
- Login Again
- Force session refresh
- Trade / market confirmations (native list, not an embedded browser)
- Setup New Account and authenticator enrollment
- Account import
- Remove from Manifest
- Authenticator deactivation
- Encryption management
- Settings
- Periodic confirmation checks and auto-confirm options
- Account filtering and reordering
- `-k` / `--encryption-key` and `-s` / `--silent`
- macOS status-bar menu and minimize-to-status-bar

Remote Steam operations (login, enrollment, live confirmations) depend on Steam and on a valid session. This release documents the ported workflows; it does not claim every live Steam path was production-tested against real accounts for this build.

## Installation

1. Download the architecture-matching DMG from this official release.
2. Open the DMG.
3. Drag **Steam Desktop Authenticator** into **Applications**.
4. Open the app.
5. If macOS blocks it because the app is unsigned and unnotarized:
   1. Open **System Settings**.
   2. Open **Privacy & Security**.
   3. Find the blocked Steam Desktop Authenticator message.
   4. Choose **Open Anyway**.
   5. Confirm **Open**.

macOS should remember that approval afterward.

Do not disable Gatekeeper globally. These steps apply only to this official download.

## Existing SDA Users

**BACK UP your original `maFiles` folder first.**

Then use **Open maFiles Folder** or **Import Account**. Encrypted source imports require the source `manifest.json`. Do not re-enroll Steam Guard unless import fails.

See `docs/macos-migration.md`.

## Known Limitations

- The app is unsigned and not notarized.
- macOS may require Open Anyway on first launch.
- The Dock icon remains visible when the main window is hidden.
- Starting a second instance exits quietly and does not focus the existing instance.
- The Intel build was produced and launched under Rosetta; it was not tested on a physical Intel Mac.

## Security

- Download only from https://github.com/Nardo021/SteamDesktopAuthenticator-macOS
- Verify the checksums below.
- Back up `maFiles` and the encryption passkey.
- This tool stores authenticator secrets on disk.

Unsigned status does not prove the application is safe. It only means Apple has not verified the developer identity.
