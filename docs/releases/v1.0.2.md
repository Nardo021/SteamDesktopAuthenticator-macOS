# Steam Desktop Authenticator macOS v1.0.2

Hotfix for v1.0.1, which crashed on launch. It is **not** upstream Windows SDA version 1.0.15.

```text
Release status: READY FOR UNSIGNED PUBLIC RELEASE
Code signing: Not provided
Apple notarization: Not provided
Gatekeeper manual approval may be required on first launch
```

This build is unsigned and not notarized by Apple. macOS cannot verify the developer identity. Only continue if you downloaded the app from the official repository and trust this project:

https://github.com/Nardo021/SteamDesktopAuthenticator-macOS

## Downloads

| Mac | File |
| --- | --- |
| Apple Silicon (M1 / M2 / M3 / M4 and later) | `Steam-Desktop-Authenticator-macOS-1.0.2-arm64.dmg` |
| Intel | `Steam-Desktop-Authenticator-macOS-1.0.2-x64.dmg` |

Apple Silicon users should use the **arm64** build. The `x64` build is for Intel Macs.

Also attach `SHA256SUMS.txt` from the same release and compare it to the DMG you downloaded.

## Changes

- Fix a launch crash in v1.0.1. Avalonia 12 threw `NullReferenceException` while loading `FontFeature` on the main window Steam Guard code. Those OpenType feature tags are removed; the code still uses Menlo.

## Installation

1. Quit Steam Desktop Authenticator completely.
2. Back up `~/Library/Application Support/Steam Desktop Authenticator`.
3. Download the architecture-matching DMG from this official release.
4. Open the DMG.
5. Replace **Steam Desktop Authenticator** in **Applications**.
6. Open the app.
7. If macOS blocks it because the app is unsigned and unnotarized:
   1. Open **System Settings**.
   2. Open **Privacy & Security**.
   3. Find the blocked Steam Desktop Authenticator message.
   4. Choose **Open Anyway**.
   5. Confirm **Open**.

Do not disable Gatekeeper globally. These steps apply only to this official download.

## Existing SDA Users

**BACK UP your original `maFiles` folder first.**

Then use **Open maFiles Folder** or **Import Account**. Encrypted source imports require the source `manifest.json`. Do not re-enroll Steam Guard unless import fails.

See `docs/macos-migration.md`.

## Known Limitations

- The app is unsigned and not notarized.
- macOS may require Open Anyway on first launch.
- The Dock icon remains visible when the main window is hidden.
- Starting a second instance exits quietly and does not focus the existing instance.
- The Intel build is produced and checked by the unsigned packaging verifier. It was not tested on a physical Intel Mac for this release.

## Security

- Download only from https://github.com/Nardo021/SteamDesktopAuthenticator-macOS
- Verify the checksums below.
- Back up `maFiles` and the encryption passkey.
- This tool stores authenticator secrets on disk.

Unsigned status does not prove the application is safe. It only means Apple has not verified the developer identity.
