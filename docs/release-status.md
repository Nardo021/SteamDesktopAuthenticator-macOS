# Release status

```text
READY FOR UNSIGNED PUBLIC RELEASE
```

v1.0.2 is an unsigned public GitHub Release. Signing and notarization are intentionally not part of this release.

```text
Code signing: Not provided
Apple notarization: Not provided
Gatekeeper manual approval may be required on first launch
```

Apple has not verified this application. macOS cannot verify the developer identity because the build does not use an Apple Developer ID certificate.

Optional Developer ID signing and notarization scripts remain in `packaging/macos/` for a later release. They are not used by the normal unsigned packaging path and are not required to build or install v1.0.2.
